# Image sizes per platform

Written 2026-11 from the platforms' published guidelines as known then. Platforms change these — when it matters (a store submission), open the official page linked and confirm.

| platform | asset | size (px) | notes |
|---|---|---|---|
| Steam | Header capsule | 920×430 | top of the store page, also used in many lists — the most-seen image |
| Steam | Small capsule | 462×174 | search results, lists — logo must read at this size |
| Steam | Main capsule | 1232×706 | front page carousel |
| Steam | Vertical capsule | 748×896 | seasonal sales pages |
| Steam | Screenshots | 1920×1080 (16:9) | at least 5; gameplay, not concept art |
| Steam | Page background | 1438×810 | optional, subtle |
| Steam | Library capsule / hero / logo | 600×900 / 3840×1240 / 1280 wide (transparent PNG) | in the player's library |
| Steam | Event cover / header | 800×450 / 1920×622 | for events and announcements |
| itch.io | Cover image | 630×500 (min 315×250) | shown in browse grids; text must be readable small |
| App Store | App icon | 1024×1024 | no transparency, no rounded corners (the store rounds them) |
| App Store | iPhone screenshots | 1320×2868 or 1290×2796 (portrait) | the largest iPhone size is required; others are scaled |
| Google Play | App icon | 512×512 | 32-bit PNG |
| Google Play | Feature graphic | 1024×500 | shown at the top of the listing and in promos |
| Google Play | Screenshots | 16:9 or 9:16, each side 320–3840 | 1080 px on the short side is a good target |
| Share preview (Open Graph) | og:image | 1200×630 (1.91:1) | used by Discord, Facebook, KakaoTalk, Reddit, LinkedIn; keep key text in the centre |
| X (Twitter) | summary_large_image | 1200×628 | close to 2:1 |
| YouTube | Thumbnail | 1280×720 (16:9) | under 2 MB; readable at phone size |

Official pages to confirm: Steamworks "Graphical Assets" documentation, itch.io creator docs, Apple "Screenshot specifications", Google Play Console "Add preview assets", the Open Graph protocol, YouTube Help "Add video thumbnails".

## Small-size test
Most people see these images tiny (search results, a phone feed). An image passes if, scaled to about 25%:
1. the game name is readable,
2. the genre is guessable (a chessboard, a pixel city, a card),
3. there is one clear focal point, not a collage,
4. it stands out next to the similar games' images (contrast, colour).
